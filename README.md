Página personal responsive donde me presento, muestro mis conocimientos en desarrollo web (HTML, CSS, Bootstrap y Tailwind CSS) y lo que estoy aprendiendo ahora: JavaScript.

Ver el proyecto publicado: https://TU-USUARIO.github.io/TU-REPO/

Descripción

Este proyecto es mi portafolio personal. Tiene cuatro secciones:

-Inicio: presentación con mi nombre y foto.
-Sobre mí: quién soy y en qué punto de mi camino como desarrolladora estoy.
-Habilidades: mis conocimientos actuales con una barra de nivel para cada herramienta.
-Aprendiendo: lo que estoy estudiando ahora (JavaScript).

Tecnologías

-HTML5
-Tailwind CSS (por CDN), con utilidades y prefijos responsive `sm:`, `md:` y `lg:`
-CSS propio (`estilos.css`) para variables de color, modo claro/oscuro, fuentes y una animación
-Fuentes de Google Fonts: Fraunces y DM Sans

Características

-Diseño responsive para celular, tablet y escritorio
-Modo oscuro automático según la preferencia del sistema
-Navegación con desplazamiento suave entre secciones
-Respeta la preferencia de movimiento reducido

Estructura del proyecto

```
mi-portafolio/
├── index.html    # contenido de la página
├── estilos.css   # variables, tema claro/oscuro y animación
├── foto.png      # foto de perfil
└── README.md
```

Cómo ejecutarlo

1.Descarga o clona el repositorio:
   git clone https://github.com/TU-USUARIO/TU-REPO.git
2.Abre `index.html` en tu navegador. No requiere instalación.

> Nota: Tailwind se carga por CDN, así que necesitas conexión a internet para ver los estilos.
